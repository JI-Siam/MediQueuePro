# MediQueuePro
Advanced Dotnet Final Project

Smart Patient Queue & Appointment Management System
Professional, modern, memorable.


Smart Queue-Based Appointment & Clinic Management System

A smart clinic management system where patients can:

book appointments,
monitor live queue positions,
receive emergency prioritization,
and doctors can manage patient flow efficiently.

The system dynamically handles:

token generation,
queue optimization,
emergency patient prioritization,
appointment tracking,
and clinic analytics.
